# Staff Home notifications

## Change

- Home role `STAFF` now exposes the notification inbox through a toolbar bell icon with the unread-count badge.
- The existing inbox screen remains the single location for notifications and notification settings.
- Profile no longer renders the notification action for `STAFF`; Parent retains its existing Profile entry point and Staff Admin already uses its Home toolbar entry point.
