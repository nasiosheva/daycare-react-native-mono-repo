# Aturan les privat khusus PAUD/TK

## Perubahan

- Menetapkan les privat sebagai layanan tambahan khusus penawaran PAUD dan TK.
- Tenant atau cabang Daycare murni tidak boleh membuat, melihat, atau menawarkan les privat kepada Parent.
- Mendokumentasikan gap saat ini: backend dan UI belum memiliki gate capability/penawaran PAUD/TK, sehingga perubahan ini adalah aturan target yang masih membutuhkan implementasi lintas backend dan frontend.
