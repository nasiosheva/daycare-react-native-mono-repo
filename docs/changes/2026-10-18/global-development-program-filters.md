# Global development program search and filters

Watermark: Mories Deo Hutapea,S.E.,S.Kom

The Platform Admin global development program catalog now supports local search by program name, description, and translated domain label. Results can also be narrowed by learning level, domain, and active/archive status. Filters can be combined and reset together; the no-match state offers a clear-all action. No API contract or stored data changes.

Verification: unit tests cover text search, combined filters, and empty results; mobile TypeScript check passes.
