# Clarify that "Muat data referensi" does not create a Global Curriculum Program

## Context

The user reported the Global Curriculum Program list on `apps/mobile/app/global-curriculum.tsx` always stayed empty after pressing "Muat data referensi" ("Load reference data"), even though the button reported success.

## Root cause

Not a bug — two distinct entities were being conflated by the copy:

- The seed button calls `POST /platform/curriculum/seed` → `GlobalCurriculumSeedingService.seed()`, which runs `db/seed/global-curriculum-seed.sql`. That script only inserts into `learning_levels`, `development_programs` (Goal Templates), and `development_program_items` (indicators) — it never inserts into `curriculum_programs`.
- The screen's visible list (`programs` query, `api.globalCurriculumPrograms(true)`) reads from `curriculum_programs` — a separate entity (business-rules.md §6.1: Program Kurikulum is a manually-curated wrapper around Goal Templates, not something auto-generated by seeding).
- The success toast's `{programs}` placeholder was bound to `developmentProgramCount` (Goal Template count), reusing the word "program" that the same screen uses for Curriculum Programs — misleading given the screen is titled around Curriculum Programs.

This matches the documented design (Program Kurikulum requires deliberate admin curation), so the fix is copy-only, not a data/caching bug.

## Changes

- `apps/mobile/src/i18n/translations.ts`: `globalCurriculum.seedSuccess`/`seedAlreadyDone` now say "Goal Template" instead of the ambiguous "program" for the `{programs}` count (id + en). Added a new `globalCurriculum.seedDescription` key explaining the seed button only loads Goal Templates and Learning Levels, and that a Global Curriculum Program still needs to be added manually via "Add global program".
- `apps/mobile/app/global-curriculum.tsx`: added a muted caption showing `globalCurriculum.seedDescription` directly under the seed button.
